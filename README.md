# Antlode

An IDM-style download manager for Windows, with a pixel-art look and an ant colony that hauls your files home.

- **Fast downloads** split into up to 32 parallel connections, with pause and resume that survive reboots
- **Video grabbing** from YouTube, X, TikTok, Reddit, Vimeo and 1,800+ other sites, in the quality you pick
- **Queue**: bulk-add dozens of links, keep the PC awake, sleep or shut down when everything is done
- **Browser extension** for Chrome, Opera, Opera GX, Edge, Brave and Vivaldi: catches downloads and adds a download bar above videos
- **Updates itself**: Antlode checks this page and offers new versions in-app

## Install

1. Download **Antlode-Setup-x.y.z.exe** from the [latest release](../../releases/latest).
2. Run it. No admin rights needed, and you can pick any folder or drive.
3. In Antlode, open **Settings → Browser extension** and follow the short guide for your browser.
